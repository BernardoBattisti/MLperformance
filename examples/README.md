# Example datasets

Small, well-known datasets for trying MLperformance. They were exported from `sklearn.datasets`.

| File | Target | Task | Rows | Source |
|---|---|---|---|---|
| `iris.csv` | `species` | Classification (3 classes) | 150 | Fisher, R. A. (1936). UCI Machine Learning Repository. |
| `breast_cancer.csv` | `diagnosis` | Classification (2 classes) | 569 | Breast Cancer Wisconsin (Diagnostic). UCI Machine Learning Repository. |
| `diabetes.csv` | `disease_progression` | Regression | 442 | Efron, B. et al. (2004). *Least Angle Regression*. Annals of Statistics. |
